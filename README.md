# NBリサーチ Webサイト(リニューアル デモ版)

接着剤・封止材の技術コンサルタント「NBリサーチ」のリニューアルサイトのデモです。

- 静的HTML / CSS / JavaScript で作成(WordPress 化する前のデモ)
- レスポンシブ対応:PC(1280px〜) / タブレット(768〜1279px) / 中間(480〜767px) / スマホ(〜479px)
- 全ページに `noindex,nofollow` を設定しているため、検索エンジンには表示されません

## ページ構成

| パス | 内容 |
|---|---|
| `/` | トップ |
| `/about/` | NBリサーチについて |
| `/service/` | 支援内容 |
| `/seminar/` | セミナー情報 |
| `/news/` | お知らせ |
| `/contact/` | お問い合わせ(送信処理は `contact/send.php`。PHP が動くサーバーで動作) |

## 注意

- GitHub Pages では PHP が動かないため、デモ版ではお問い合わせフォームの送信はできません。
- 本番公開前に `contact/send.php` 冒頭の送信先メールアドレスを設定してください。
